NODE #1 - WEB-FRONTEND-SERVER1

Welcome to MyMiniCloud – Served by: web-frontend-server1

Hệ thống mô phỏng hạ tầng đám mây môn Điện toán đám mây (TDTU). Request hiện tại đang được xử lý bởi web-frontend-server1 thông qua Nginx Load Balancer (Round Robin).

Các đường dẫn dịch vụ trong hệ thống:

  • Trang Blog cá nhân (/blog/)
  • Kiểm tra Backend API (/api/hello)
  • Danh sách sinh viên JSON (/student/)
  • Keycloak Authentication (/auth/)
  • Prometheus Targets (:9090)
  • Grafana Dashboard (:3000)
