Keycloak Admin Console

Token verification flow

Luồng xác thực hiện có trong Flask

  1. Client → KeycloakNgười dùng xác thực tại Keycloak để nhận access token.
  2. Client → FlaskGửi Bearer Token đến GET /api/secure qua Gateway.
  3. Flask → Keycloak JWKSĐọc khóa công khai, kiểm tra chữ ký RS256, issuer, audience và hạn sử dụng.
  4. Flask → ClientTrả JSON nếu token hợp lệ; token thiếu hoặc không hợp lệ trả 401.
Issuer trong Compose hiện là http://localhost:8081/realms/realm_52400114. Token cấp qua hostname khác có thể không khớp issuer. Giao diện không thay đổi cấu hình JWT.

Deployment notes

Local Docker & AWS EC2

Truy cập qua Gateway cổng 80. Console dùng các cổng publish riêng; khả dụng phụ thuộc firewall và Security Group.

Với HTTPS hoặc tên miền riêng, cập nhật URL công khai trong assets/config.js và đồng bộ ba frontend. Không gửi token qua kết nối không tin cậy.
