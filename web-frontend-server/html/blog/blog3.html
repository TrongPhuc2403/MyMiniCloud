01 / KHÁI NIỆM

AWS EC2 là gì?

Amazon Elastic Compute Cloud (Amazon EC2) là dịch vụ cung cấp máy chủ ảo trên hạ tầng AWS. Người dùng có thể lựa chọn hệ điều hành, cấu hình tài nguyên và triển khai ứng dụng theo nhu cầu.

Thay vì vận hành một máy chủ vật lý riêng, bạn khởi tạo một EC2 Instance, kết nối đến máy chủ và cài đặt môi trường chạy ứng dụng của mình.

Một máy chủ, nhiều khả năng

Với một Instance chạy Ubuntu, bạn có thể cài Docker và chạy các dịch vụ Web, Application, Database dưới dạng Container. Bạn vẫn quản lý hệ điều hành, ứng dụng và cấu hình truy cập của máy chủ.

02 / CÁC THÀNH PHẦN QUAN TRỌNG

Hiểu hạ tầng trước khi triển khai

Ba thành phần dưới đây giúp bạn hình dung nơi ứng dụng chạy, cách truy cập và cách dữ liệu được lưu trữ.

EC2 Instance — Máy chủ ảo

Nơi chạy hệ điều hành và ứng dụng. Bạn lựa chọn cấu hình CPU, bộ nhớ và Amazon Machine Image (AMI), chẳng hạn một AMI Ubuntu phù hợp.

Security Group — Kiểm soát lưu lượng

Tập hợp các quy tắc kiểm soát lưu lượng mạng vào và ra của Instance. Với máy chủ web, cấu hình cổng theo nhu cầu truy cập và chỉ cho phép SSH từ nguồn tin cậy.

Amazon EBS — Lưu trữ dạng khối

Elastic Block Store cung cấp các volume gắn vào Instance để lưu hệ điều hành và dữ liệu. Khả năng giữ lại volume khi xóa Instance phụ thuộc vào cấu hình của từng volume.

03 / QUY TRÌNH TRIỂN KHAI

Từ Ubuntu đến ứng dụng đang chạy

Quy trình cơ bản bắt đầu từ việc chuẩn bị máy chủ, sau đó thiết lập môi trường và khởi động các dịch vụ của dự án.

  1. Khởi tạo EC2 Instance

    Chọn AMI Ubuntu, loại Instance và dung lượng lưu trữ phù hợp. Chuẩn bị phương thức kết nối SSH và cấu hình mạng để truy cập máy chủ.

  2. Cấu hình Security Group

    Cho phép SSH từ địa chỉ IP quản trị. Mở cổng HTTP hoặc HTTPS khi cần phục vụ website; giữ các cổng cơ sở dữ liệu trong phạm vi nội bộ.

  3. Kết nối và chuẩn bị môi trường

    SSH vào Instance, cài Docker Engine và Docker Compose theo hướng dẫn dành cho Ubuntu. Đưa mã nguồn, file Compose và cấu hình cần thiết lên máy chủ.

  4. Khởi động và kiểm tra dịch vụ

    Chạy Docker Compose tại thư mục dự án. Sau đó kiểm tra trạng thái Container, đọc log và truy cập ứng dụng để xác nhận hoạt động.

Terminal · EC2 Ubuntu 
docker compose up -d

Chạy tại thư mục chứa file Compose, khi Docker hoạt động và các biến môi trường cần thiết đã được cấu hình. Nếu dự án yêu cầu build Image tại máy chủ, dùng thêm --build.

Xác nhận ứng dụng hoạt động

Dùng docker compose ps để xem trạng thái và docker compose logs để đọc log. Một Container đang chạy chưa đủ để kết luận ứng dụng hoạt động: hãy kiểm tra phản hồi HTTP hoặc chức năng đại diện của hệ thống.

04 / TỪ LOCAL ĐẾN CLOUD

AWS EC2 trong MyMiniCloud

Hệ thống MyMiniCloud sẽ được triển khai trên máy chủ AWS EC2 để kiểm tra khả năng vận hành các dịch vụ Container trong môi trường Cloud thay vì chỉ chạy trên local.

Docker Compose tổ chức các dịch vụ trên Instance, trong khi EC2 cung cấp tài nguyên máy chủ. Việc kiểm tra tập trung vào truy cập web qua Nginx, xử lý của ứng dụng Flask và kết nối tới MariaDB.

Mô hình triển khai trên một Instance phù hợp cho học tập và thử nghiệm. Khả năng chịu lỗi, mở rộng và sao lưu cần được thiết kế thêm khi yêu cầu vận hành tăng lên.

Điểm cần nhớ

EC2 cung cấp máy chủ ảo, Security Group kiểm soát lưu lượng và EBS cung cấp lưu trữ. Docker Compose giúp triển khai các dịch vụ ứng dụng trên nền hạ tầng đó.
