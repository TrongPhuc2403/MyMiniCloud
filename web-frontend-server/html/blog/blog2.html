01 / KHÁI NIỆM

Docker là gì?

Docker là nền tảng hỗ trợ đóng gói và triển khai ứng dụng thông qua Container. Mỗi Container chạy ứng dụng cùng các thành phần phụ thuộc cần thiết, như thư viện và môi trường thực thi.

Nhờ cách đóng gói này, bạn có thể triển khai ứng dụng nhất quán hơn giữa các môi trường tương thích, từ máy phát triển đến máy chủ.

Nhẹ và tách biệt

Các Container có môi trường tiến trình và hệ thống tệp được cô lập, nhưng chia sẻ kernel của máy chủ chạy chúng. Vì vậy, Container thường nhẹ hơn một máy ảo chứa hệ điều hành riêng.

02 / HAI KHÁI NIỆM CỐT LÕI

Docker Image và Container

Image và Container có liên hệ chặt chẽ, nhưng đảm nhiệm hai vai trò khác nhau trong quá trình triển khai.

Image — Mẫu đóng gói

Docker Image chứa mã ứng dụng, thư viện và cấu hình môi trường thực thi. Image gồm các lớp chỉ đọc và được dùng làm mẫu để tạo Container.

Container — Thể hiện của Image

Container được tạo từ Image, có thêm lớp ghi riêng và có thể được khởi động, dừng hoặc xóa. Bạn có thể tạo nhiều Container độc lập từ cùng một Image.

Ví dụ thực tế

Từ cùng một Image của ứng dụng Flask, bạn có thể tạo nhiều Container để chạy các bản ứng dụng riêng biệt. Dữ liệu cần lưu lâu dài nên được đặt trong volume hoặc một hệ thống lưu trữ phù hợp.

03 / QUẢN LÝ NHIỀU DỊCH VỤ

Kết nối hệ thống với Docker Compose

Docker Compose giúp định nghĩa và quản lý nhiều Container thông qua một file YAML. Các thành phần như network, volume, port và environment được cấu hình tập trung.

Thay vì khởi chạy từng Container thủ công, bạn có thể dùng một lệnh để build và khởi động các dịch vụ được khai báo trong cấu hình Compose.

Terminal · Docker Compose 
docker compose up -d --build

Chạy tại thư mục chứa file cấu hình Compose, trên máy đã cài Docker Engine và Docker Compose.

up
Tạo và khởi động các dịch vụ.
-d
Chạy các Container ở chế độ nền.
--build
Build Image cho các dịch vụ có cấu hình build trước khi khởi động.
04 / TỪ LÝ THUYẾT ĐẾN THỰC HÀNH

Docker trong MyMiniCloud

Trong mô hình MyMiniCloud, các dịch vụ được triển khai thành những Container riêng biệt. Các Container giao tiếp thông qua Docker Network cloud-net, giúp mô phỏng kiến trúc nhiều máy chủ.

Nginx, ứng dụng Flask và cơ sở dữ liệu MariaDB có thể được tổ chức thành các dịch vụ độc lập trong Docker Compose. Cách phân tách này giúp theo dõi, cấu hình và quản lý từng thành phần rõ ràng hơn.

Docker ImageContainerComposecloud-netVolume
Điểm cần nhớ

Image là mẫu đóng gói. Container là thể hiện được tạo từ Image. Docker Compose kết nối nhiều dịch vụ thành một hệ thống có cấu hình tập trung.
